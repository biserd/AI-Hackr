# Decisions and deviations

1. Preserve existing React/Vite/Express, verified identity and scanner. The empty-repository Next.js/Fastify/pnpm defaults do not justify replacing an existing product. The additive service has its own committed npm lockfile and PostgreSQL boundary.
2. Use a PostgreSQL durable queue and transactional outbox instead of BullMQ for AIHackr jobs. Reserve/create/outbox are atomic; leased SKIP LOCKED claims consume durable rows directly, eliminating an external queue-publish gap. This does not replace upstream Firecrawl queues. Multi-process PostgreSQL load/recovery remains a deployment test.
3. PGlite is local/CI only, running actual PostgreSQL SQL with serialized local transactions. It does not prove multi-process lock behavior. Production requires PostgreSQL.
4. Guarded HTTP is verified; the Firecrawl private browser adapter is gated. The inspected public engine API does not guarantee bounded fetch choice. Full core reuse and browser hardening remain unfinished, explicitly rather than claiming M1 completion.
5. JSONB result storage initially replaces the proposed S3 backend. Content is tenant-authorized and expires after 24 hours. Object-store offload, lifecycle behavior and measured storage costs remain future work.
6. All paid operations are asynchronous. REST, MCP and dashboard share acceptance and billing. Compatibility polls the same jobs for up to 20 seconds.
7. Extraction rejects refs, unknown keywords, deep schemas and unbounded arrays. Enumerated o200k models have operator-configured integer token rates. Plain retrieval never invokes a model. Missing evidence remains partial.
8. A maintained hosted OAuth provider is required. Keycloak template illustrates PKCE S256, exact redirects, consent and audience. The database binds issuer+subject+registered client to one owner-selected tenant; arbitrary JWT tenant claims are ignored. Connection revocation is checked per request; provider-wide instant JWT revocation/introspection is not implemented. Use five-minute provider tokens.
9. The OpenAI packaging page shows a server-level auth extension, but the downloaded portable MCP 1.0.0 schema rejects extensions there. The validated package uses standard OAuth resource discovery and no unsupported fields. Actual host behavior remains a separate test.
10. Content/cache lasts 24 hours; terminal job/result/unit/event/idempotency rows are removed 30 days after terminal update. Financial ledger rows remain under the accounting policy. Daily caps count accepted jobs by UTC creation date, holding active ceilings and using terminal actual charges. Cap edits do not revoke already accepted budgets; connection revocation blocks new scheduling.
11. Live Stripe keys/events are rejected. Production billing, browser enablement, paid providers, deployment, hosted-client tests, representative live benchmark and public review are separate gates. Fixture timings are not web latency or margin claims.
