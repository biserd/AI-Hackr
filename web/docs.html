Your tools.

AIHackr runs entirely on Cloudflare. Browser Run handles rendering and managed crawls; our open-source gateway provides workspace authentication, bounds and retained results. MCP uses Cloudflare’s official open-source tool implementations.

Your account and API keys

Create an account or sign in on the homepage using the code sent to your email. The playground uses a secure, HttpOnly session cookie; you do not need to paste a key. For your code or agents, open API keys, create a named key and send it as Authorization: Bearer YOUR_API_KEY. Each key belongs to your account, is shown only once and can be revoked. Keys are never sent to target sites or included in URLs.

REST

POST /v2/scrape — one public URL; select one of markdown, html or links in formats.
POST /v2/map — same-origin links discovered on the submitted page; limit 1–100. This is page-level discovery, not a whole-site sitemap.
POST /v2/extract — one url (or a one-item urls array), a prompt and/or JSON schema. Uses Browser Run and AI inference.
POST /v2/crawl — asynchronous managed crawl; supply url, limit, depth, render and formats.
GET /v2/crawl/:id — status and up to 10 records; follow next for remaining retained results.
DELETE /v2/crawl/:id — cancel the workspace job.

Crawl defaults: 20 pages, depth 2, browser rendering. Maximum: 100 pages, depth 5, two active crawls. Set render: false for static HTML retrieval without executing JavaScript. Site rules may disallow crawling. Same-origin crawling is enforced; target cookies, custom headers, scripts, actions and webhooks are rejected.

The /v2 routes provide a documented Firecrawl-shaped subset for migration. This service does not run the Firecrawl engine and does not promise full SDK/API compatibility. Unsupported options return explicit errors. Search and batch scraping are unavailable.

MCP

Connect a Streamable HTTP MCP client to https://aihackr.com/mcp, with the API key from your account. Tool names come from Cloudflare’s official server:

get_url_html_content
get_url_markdown
get_url_links
scrape_url_elements
get_url_json
start_crawl
get_crawl_result
cancel_crawl

Account selection is fixed on the server. Do not pass Cloudflare credentials or account identifiers. Browser administration, screenshots and PDF tools are not exposed. MCP output is bounded; use REST pagination for full retained results. Hosted OAuth account linking is not enabled.

Credits and paid plans

Every verified account starts with 20 lifetime credits. Starter is $9/month for 1,000 credits, Builder $29/month for 5,000, Scale $79/month for 20,000. Prices are USD; tax collection is off. Monthly credits expire at the end of the paid period and do not roll over. There are no automatic overage payments. New work pauses when available credits run out. Manage your plan in the dashboard.

Scrape and Map cost 1 credit per successful request; Extract costs 5 per successful request. Crawl holds its requested page limit, then charges 1 credit for each successful page and returns unused credits when the job reaches a terminal state, including cancellation. A failed request with no usable result returns its hold. Polling and downloads have no additional credit cost. Background reconciliation settles crawls even if you close the website. Holds stay attached to their original allowance across a billing boundary; expired credits cannot roll into a new period.

Stripe-hosted Checkout starts subscriptions. The Customer Portal handles payment methods, invoices, upgrades, downgrades and cancellation. Credits are granted only from paid Stripe invoices, with idempotent invoice grants. Upgrades add the net prorated credit difference after payment; downgrades and cancellation take effect at period end. Refunds, disputes and fraud signals pause new work for billing review. Checkout return URLs cannot grant credits.

Existing trial reservations become the opening spent balance; sign-ins and key changes do not reset it. Use GET /api/usage for the credit ledger and complete daily aggregates, and GET /api/jobs for paginated private history. Follow each response's next cursor. Completed result downloads use GET /api/jobs/:id.

Idempotency, limits and retention

For POST operations, send an Idempotency-Key header with 16–128 letters, digits, hyphens or underscores. Retry the same body and key to reuse a completed result, avoiding another browser call and credit charge. A different body with the same key returns 409. An in-progress page request returns 409; check history before retrying. A repeated crawl creation returns the original workspace job ID. Idempotency keys are account-scoped. Retained results expire after 7 days; expired keys cannot launch work again.

Each workspace allows three concurrent requests, 30 engine operations/minute, two active crawls, 100 pages/crawl and depth 5. A shared 1,000-page daily provider budget bounds total launch-stage browser spend; attempted provider capacity is not refunded to this operational budget. This guard is separate from refundable customer credits. Rate or budget limits return an explicit error without customer credit spend. Sign-in codes expire after 10 minutes, allow five attempts and are single use. Sessions expire after seven days. Completed crawl records are limited to 60,000 characters per format with truncation warnings; completed page outputs are bounded by the provider response limit.

Plugin preparation

Download the portable plugin development package. It declares API-key Bearer authentication for compatible clients, with no secrets in the package. OAuth and public ChatGPT plugin submission are deferred. The current ChatGPT submission portal does not provide fixed API-key linking, so this is not advertised as a published ChatGPT plugin.

Cloudflare charges the operator for applicable Browser Run, Workers, Durable Objects and AI usage. Firecrawl Cloud is not called. No anti-bot bypass or guaranteed target-site success is promised. DNS validation is an admission check; browser redirects and subresources remain subject to Cloudflare’s protections.
