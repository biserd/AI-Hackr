BEFORE YOU BUILD
Common questions.
What is AIHackr?
AIHackr is a web scraping API and browser playground for public webpages. Retrieve Markdown, HTML, links or structured JSON, run bounded crawls, or connect a compatible MCP client. The engine is Cloudflare Browser Run.
Do I need an API key to use the playground?
No. Sign in with an email code and use your private workspace. Create an API key for REST requests or for MCP clients that use a bearer token. See accounts and API keys.
What do the free credits include?
Each verified account starts with 1,200 free credits each month. Scrape and Map cost 1 credit per successful request; Extract costs 5; Crawl costs 1 per successful page. Jobs hold their maximum cost while running and release unused credits when terminal. No card is required. Compare monthly plans.
Can I scrape JavaScript websites?
Browser rendering can read JavaScript-produced content. Access still depends on the target’s behavior, robots rules and provider restrictions. Logged-in target sessions, CAPTCHA solving and anti-bot bypass are not offered.
Does AIHackr run Firecrawl?
No. It runs Cloudflare Browser Run and uses official Cloudflare OSS MCP tools. The REST API exposes a documented Firecrawl-shaped subset; full SDK or feature compatibility is not promised. Read the migration guide.
Are paid plans and ChatGPT OAuth available?
Monthly subscriptions are available from your dashboard through Stripe Checkout, with invoices and cancellation in the customer portal. Connect ChatGPT or another compatible MCP client with OAuth using the web scraping MCP server guide.
